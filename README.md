# Anvi Wadhwa — Retro Space Portfolio

The repository root contains the published GitHub Pages build. The editable Vue source lives in [`portfolio-app/`](portfolio-app/).

## Run locally

```sh
cd portfolio-app
npm install
npm run dev
```

## Publish an update

From `portfolio-app/`, run `npm run publish:pages`. This builds the app for the `/anvisgit/` GitHub Pages path and copies the production files to the repository root. Commit both the source and generated site files.
